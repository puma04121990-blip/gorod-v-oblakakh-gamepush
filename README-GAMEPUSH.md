# Город в облаках — билд под GamePush

Та же idle-игра, уже обвязанная под документацию GamePush.
Без чатов, кланов, лидербордов и покупок.

Исходный `index.html` лежит в репозитории [cat-evolution-game](https://github.com/puma04121990-blip/cat-evolution-game).

## Что GamePush добавляет сам, а что нет

GamePush **не дописывает игру**. Он не ставит кнопки рекламы и не придумывает гранты.

| Делает GamePush | Делаешь ты |
|---|---|
| Подключает SDK площадок | Вставляешь один загрузчик из кабинета |
| Показывает рекламу, когда игра вызвала `gp.ads` | Ставишь кнопки и награды |
| При дистрибуции оформляет площадки | Готовишь билд, тексты, картинки |
| Платит в рублях | Сдаёшь заявку |

Не подключай пока: чаты, лидерборды, уникальные ники, покупки. Это лишние запросы к облаку GamePush.

## Кабинет

1. https://gamepush.com/auth/
2. Проект «Город в облаках»
3. Строковое поле игрока `save`
4. Вставить загрузчик SDK в `index.html`
5. Дистрибуция: покупок нет, язык русский
