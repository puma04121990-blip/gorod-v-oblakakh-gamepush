# Мицелий — билд под GamePush

Автономная idle-игра. Нет чатов, кланов, лидербордов и покупок.
Нет запросов и файлов из других репозиториев.

## Запросы

Запрос = вызов облака GamePush, не клик по колонии.

- один раз при входе (`player.ready` + чтение поля `save`)
- затем не чаще чем раз в 2,5 секунды пачкой, плюс автосейв раз в 15 секунд
- после росы, разведки, буста, сброса

Реклама `showRewardedVideo` / `showFullscreen` не тарифицируется.

## Что уже встроено

- `window.onGPInit` — ждёт игрока, грузит `save`, preloader, sticky, `gameStart()`
- локальный fallback, если SDK нет
- пауза на рекламе и при скрытии вкладки
- rewarded: роса с поверхности, ×2 рост на 2 минуты, вернуть нить, удвоить оффлайн
- fullscreen после нового слоя и после находки, не раньше 60 сек сессии и не чаще 3 минут
