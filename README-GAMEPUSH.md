# Горн — GamePush

Игра живёт в одном `index.html`. Нет картинок, музыки и ссылок на другие репозитории.

## В кабинете

1. Создать проект «Горн».
2. Строковое поле игрока `save`.
3. Вставить загрузчик SDK в конец `index.html`.
4. Покупок нет, язык русский.

## Запросы

Облако пишется не чаще чем раз в 2,5 сек и раз в 15 сек.
Реклама не тарифицируется.
Чаты, лидерборды и покупки не подключены.
