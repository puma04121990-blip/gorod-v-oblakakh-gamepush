# Город в облаках

Русскоязычная HTML5 idle-игра про развитие небесной столицы. Этот репозиторий — билд под [GamePush](https://gamepush.com).

**Играть:** откройте `index.html` или [GitHub Pages](https://puma04121990-blip.github.io/gorod-v-oblakakh-gamepush/) после включения Pages.

## Что внутри

- заряд ядра, пассивный доход, 8 улучшений, 10 районов
- экспедиции, контракты, исследования, новая высота
- обвязка GamePush: облачный сейв, rewarded, редкий fullscreen
- без чатов, лидербордов и покупок

## Локальный запуск

Откройте `index.html` в браузере. Без SDK прогресс пишется в `localStorage`.

Иллюстрации и музыка подгружаются с публичного репозитория `cat-evolution-game`.

## Подключение GamePush

1. Создайте проект в [кабинете](https://gamepush.com/auth/).
2. Добавьте строковое поле игрока `save`.
3. Вставьте загрузчик SDK в комментарий `GAMEPUSH SDK` в конце `index.html`.
4. Подробности — в `README-GAMEPUSH.md`.

## Лицензия

Исходники для публикации игры на площадках владельца репозитория.
