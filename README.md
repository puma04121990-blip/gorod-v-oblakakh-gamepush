# Горн

Самостоятельная русскоязычная HTML5 idle-кузница.
Один файл, без сторонних репозиториев, CDN-картинок и внешней музыки.

**Играть:** откройте `index.html`.

## Чем отличается

Это не небесный город. Здесь другой мир: очаг, искры, закалка, караваны и новый сплав.

## Геймплей

- удар по наковальне
- 8 улучшений и 10 стадий горна
- заказы, события, караваны, исследования
- оффлайн-награда и престиж

## GamePush

В игре уже есть `window.onGPInit`, облачное поле `save`, rewarded и редкий fullscreen.
Без SDK всё работает на `localStorage`.

1. Создайте проект в кабинете GamePush.
2. Добавьте строковое поле игрока `save`.
3. Вставьте загрузчик SDK в комментарий в конце `index.html`.
